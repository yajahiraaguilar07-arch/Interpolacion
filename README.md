Interpolación de Lagrange vs. Diferencias Divididas de Newton

SCC-1017 Métodos Numéricos

Práctica: Interpolación de Lagrange vs. Diferencias Divididas de Newton.

Descripción

Este proyecto implementa dos métodos de interpolación numérica utilizando Java: el método de interpolación de Lagrange y el método de diferencias divididas de Newton.

El objetivo es comparar ambos métodos para aproximar valores a partir de un conjunto de puntos conocidos, analizar sus resultados numéricos y comprender su funcionamiento.

Métodos implementados

- Interpolación de Lagrange: calcula el polinomio interpolador mediante la construcción de los polinomios base de Lagrange.
- Diferencias Divididas de Newton: construye el polinomio interpolador utilizando una tabla de diferencias divididas.

Tecnologías utilizadas

- Java
- IntelliJ IDEA

Estructura del proyecto

- "Main.java": ejecución y pruebas de los métodos.
- "InterpolacionLagrange.java": implementación del método de Lagrange.
- "DiferenciasDivididasNewton.java": implementación del método de Newton.

Pruebas

Se utilizarán conjuntos de nodos y puntos de evaluación para comparar los resultados obtenidos mediante ambos métodos.

Objetivo académico

Aplicar métodos numéricos de interpolación, verificar sus resultados y analizar sus características computacionales.
